Ke Mana Data Reservasi Masuk?

Website ini mendukung 3 jalur penyimpanan data pendaftar sekaligus:

  1. Dashboard Admin Lokal (admin.html): Setiap form yang diisi langsung tercatat di tabel halaman ini dan bisa di-export ke Excel (`.csv`).
  2. WhatsApp Resmi (0878-2428-0277): Saat tamu klik konfirmasi, detail lengkap otomatis terkirim ke WhatsApp Admin Reve Space.
  3. Google Sheets / Webhook Cloud (Opsional saat Website Online): Tempelkan URL Google Apps Script Web App atau Formspree / Make.com Webhook di bawah ini agar setiap pendaftar dari HP/komputer mana pun langsung masuk ke Google Sheets Anda secara real-time.
Jika diisi, setiap submit di booking.html otomatis mengirimkan JSON data pendaftar ke URL ini.
